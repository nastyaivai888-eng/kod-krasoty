# КОД КРАСОТЫ — публикация на Render (предпросмотр)

**Внимание: этот пакет предназначен только для предпросмотра, НЕ для приёма реальных заказов.** Переключатель `DEMO_MODE=1` отключает оформление заявок и перевод на оплату.

1. Создайте приватный репозиторий на GitHub и загрузите туда содержимое этой папки (файлы `server.py`, `render.yaml`, `requirements.txt`, `index.html`, `cover.png`, папку `private`). **Не делайте репозиторий публичным:** внутри `private/guide.pdf` находится платный материал. Для настоящего запуска потребуется вынести его в закрытое объектное хранилище; хранить коммерческий PDF в git — временное демонстрационное решение.
2. Зарегистрируйтесь на https://render.com и выберите **New → Blueprint**. Подключите приватный GitHub-репозиторий и подтвердите развёртывание `render.yaml`.
3. Дождитесь статуса **Live**. Render выдаст адрес вида `https://kod-krasoty-preview-....onrender.com` (точный адрес определит Render).
4. Откройте сайт, проверьте обложку, текст, мобильную версию и страницу `/order`: она должна сообщать, что оплата отключена.
5. **Не меняйте `DEMO_MODE` на `0` для настоящих покупателей.** На бесплатном Render локальная SQLite-база непостоянна: при перезапуске/переразвёртывании можно потерять заказы и доступы. Перед коммерческим запуском необходимы постоянная БД, надёжная аутентификация, CSRF-защита, ограничение попыток входа, защищённое хранение файла, бэкапы, политика конфиденциальности и юридические реквизиты ИП.
6. Не публикуйте пароль администратора или секреты. `ADMIN_PASSWORD` создаётся Render автоматически. Для реальной эксплуатации нужна отдельная безопасная схема входа.

**Платёжная ссылка:** https://pay.kaspi.kz/pay/w6fc4b8h — принадлежит ИП партнёра. В демонстрационной сборке кнопка оплаты ведёт только на страницу с сообщением о подготовке. Автоматическая проверка Kaspi Pay отсутствует.

**До запуска продаж:** вычитать медицинские формулировки пособия, проверить права на иллюстрации, реквизиты продавца, чек, условия продажи, соответствие ОКЭД и обработку персональных данных.
