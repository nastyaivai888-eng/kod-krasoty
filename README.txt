КОД КРАСОТЫ — прототип сайта с защищённой выдачей после РУЧНОГО подтверждения Kaspi Pay

1. Требования: Python 3.10+, pip install pymupdf pillow
2. Установите длинный пароль администратора: export ADMIN_PASSWORD='длинный_случайный_пароль'
3. Запуск: python server.py
4. Откройте http://127.0.0.1:8080/ — страница продажи; /order — заказ; /admin — ручное подтверждение оплаты.
5. После реального поступления 4990 ₸ в Kaspi Pay подтвердите заказ в /admin. Ссылка покупателя показывается один раз — скопируйте её и отправьте покупателю.
6. Защищённые страницы отдаются только с действующим токеном, с индивидуальной маркировкой. Исходный PDF находится в папке private, не должен быть доступен из веб-сервера.

ВАЖНО ДО РЕАЛЬНОГО ЗАПУСКА:
- Это демонстрационный код, НЕ развернутый публичный сервис. HTTPS, домен, резервные копии, журнал аудита, rate limiting, CSRF-защита, надёжная админ-аутентификация и политика хранения данных требуют доработки и проверки специалистом.
- Нет автоматического подтверждения Kaspi: платежи проверяются ВРУЧНУЮ в аккаунте продавца. Скриншот оплаты не подтверждение.
- Не включать реальные продажи до проверки реквизитов ИП, налогового режима, чеков, условий покупки и согласия на обработку персональных данных.
- PDF в private/guide.pdf — текущая собранная версия. Перед коммерческой продажей провести окончательную редактуру и проверить права на все иллюстрации.
- Полностью запретить скриншоты и фотографии экрана невозможно. Покупатель может передать личную ссылку другому человеку; для предотвращения этого нужны дополнительная аутентификация и ограничения сессий.
- При переносе сайта на другой домен менять платёжную ссылку только после подтверждения владельца Kaspi Pay.
